# Instruksi
## Pembuatan Proyek

Buatlah sebuah chatbot berbasis AI dengan use case dan konfigurasi parameter yang sesuai dengan
kreativitas masing-masing. Chatbot harus menggunakan model AI (misalnya NLP/LLM) untuk memproses
bahasa alami dan memberikan respon yang relevan kepada pengguna.

● Use Case: travel assistant

● Parameter Kreatif: gaya bahasa (formal/santai), domain pengetahuan pariwisata jogja, bali, bandung, integrasi API eksternal, atau fitur tambahan seperti memory (sqlite) dan
rekomendasi.
